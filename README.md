# 囑託測量收費試算

法院或行政執行分署囑託之現況測量、非屬建物位置面積測量、共有物分割方案的收費試算工具。取代 `docs/原始試算表_v2.1.xlsx`。

## 使用方式

- **直接開**：下載 `index.html`，用 Chrome 或 Edge 雙擊開啟即可，不需安裝、不需網路（沒網路時字型改用電腦內建字型）。
- **列印**：按右側「列印 A4 報表」，印表機選 A4。方案很多時報表會自動縮小，保證一張 A4。
- **存檔**：資料會自動留在這台電腦的瀏覽器裡。要交給別人或留存，用「匯出檔案」存成 `.json`，之後「匯入檔案」即可還原。

## 欄位對照（原試算表彩色欄位 → 計算器）

| 原試算表「資料欄」 | 計算器位置 |
|---|---|
| D2 建物位置費 有幾格 | 建物部分 → 建物棟數 |
| H2:K29 面積費計算（灰色欄） | 建物部分 → 各建號／各層面積（新增列） |
| D5–D8 非屬建物各級距格數 | 非屬建物 → 基本費 → 各閉合區面積級距（下拉選單） |
| D9 總共幾個點（施測費） | 非屬建物 → 施測費 → 鑑定點總數 |
| E6 多方案展示註記 | 非屬建物 → 展示在幾個方案上（預設 1） |
| D10 總共幾個點（面積） | 非屬建物 → 需算面積物件的折點數 |
| D11 製圖張數 | 雜項・製圖費 → 來函需求張數 |
| D14–D17／D20–D23／D26–D29 分割前面積級距 | 共有物分割方案 → 分割前地號面積級距（各方案共用，填一次） |
| D18／D24／D30 線段數 | 共有物分割方案 → 各方案卡的「線段數」 |

甲乙丙三案改為「分割方案數量」：填 10 就產生 10 張方案卡（甲～癸），超過 10 案以「第 11 案」起命名，名稱可自行修改。

## 計收原則（已確認）

1. 分割方案基本費：多項方案僅收一次，施測費各案分別計收（第 4 條第 1 項第 1 款）。
2. 非屬建物：填「展示在幾個方案上」（預設 1）。基本費僅收一次，施測費 × 方案數（內規(三)）。
3. 限期 15 日內加倍：只加倍現況測量費與分割方案費，製圖費不加倍。
4. 製圖費：每張 20 元，第一張免收。

與原試算表的其他差異見 [`docs/規定與計算邏輯檢查.md`](docs/規定與計算邏輯檢查.md)。

## 更新費率

費率集中在 `index.html` 的 `RATES` 物件（`<script>` 開頭），法規修正時只改那裡。

## 散佈給同事

- **可散佈檔案**在 `dist/`：
  - `囑託測量收費試算_v1.0.html`：單一檔案，直接傳給同事即可。
  - `囑託測量收費試算_v1.0.zip`：計算器＋使用說明＋規定檢查報告。
- 改版時：修改 `index.html` 裡的 `VERSION`，執行 `./scripts/build.sh` 重新產生 `dist/`。
- 或在 GitHub 開啟 Pages（Settings → Pages → 選本分支／根目錄），同事用網址開啟，永遠是最新版。
