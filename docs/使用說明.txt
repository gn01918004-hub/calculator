囑託測量收費試算　使用說明
================================

一、開啟
  雙擊「囑託測量收費試算_v1.5.0.html」，用 Chrome 或 Edge 開啟。
  不需安裝，也不需網路（沒有網路時字型會改用電腦內建字型，計算不受影響）。

二、填寫
  先在「案件資訊」下方的「收費項目」按下本案需要的項目，對應的區塊才會出現。
  右上角「相關規定」可隨時查閱條文與附表。
  數字欄可以直接打全形數字（例：１２３），不是數字的欄位會標紅框。
  名詞旁的「?」可以點開看定義。
  淡黃底的欄位都是需要人工填寫的地方，請依來函逐項填入：
  1. 案件資訊：囑託機關、來文字號、案號、地段地號（只印在報表上）。
     限期 15 日內辦理者請勾選，建物、非屬建物、分割方案費會加倍
     （製圖費與判決確定分割不加倍）。
     法院會勘前已預收費用時，填在「會勘前預繳費用」，試算時會自動扣除，
     右側大字改顯示「尚應補繳」或「應退還」的金額。
  2. 建物部分：建物棟數／閉合區數（同一棟多個閉合區各算一格）；
     各層各閉合區面積（每 50 平方公尺一單位）。
  3. 非屬建物：各閉合區面積級距、鑑定點總數、需算面積物件的折點數、
     展示在幾個方案上（預設 1，基本費只收一次，施測費依方案數計收）。
  4. 製圖費：來函需求張數（每張 20 元，第一張免收）。
  5. 共有物分割方案：先填「分割方案數量」，會自動產生對應數量的方案卡；
     分割前地號只填一次（基本費僅收一次），各方案卡填線段數。
  6. 判決確定分割（判決後另案申請的預估，不計入應收合計）：可從分割方案選一案帶入。
     依判決／調處申請且無需實地測量者（基本費＋施測費）÷ 2；
     需實地測量或確定界址點者原價計收，界址點每點 200 元另加。
     要分攤到各共有人，請用「共有物分割複丈費清冊」。
  右側試算單會即時顯示每一項的計算式與應收合計；漏填時會出現黃色提醒。

三、列印
  「👁 預覽報表」：先在畫面上看報表，確認後再印。
  「🖨 列印 A4 總表」：全部費用印成一張 A4。
  「🖨 列印各方案分算明細」：每個分割方案各印一張 A4。
     基本費預設由第一案收取，可在「各方案分算」改由其他案收取；
     建物、非屬建物、製圖費等共同費用可併入該案或另列一張。
  印表機紙張選 A4，內容多時會自動縮小。

四、案件與存檔
  資料會自動保存在這台電腦的瀏覽器中，可以同時存很多件案件。
  上方「目前案件」可以切換案件；「＋ 新案件」開新案；「刪除本案」要按兩次才會刪。
  右上角「📁 檔案」選單：
    匯出本案 JSON：交給同事或留存單一案件。
    下載備份（全部案件）：一次備份所有案件，換電腦或重灌前建議先下載。
    匯入案件／備份：單一案件會新增為一件；全部備份會整份還原。

五、更新
  開啟計算器時會自動檢查新版本（需連網）。有新版會跳出「有新版本可以下載」：
    1. 先按「先匯出備份」保存目前的資料。
    2. 按「下載新版」，在 GitHub 頁面按下載鍵取得新的 .html 檔。
    3. 用新檔取代舊檔，用同一個瀏覽器開啟，原本的資料會保留。
  暫時不想更新可按「稍後再說」；按「略過這個版本」則這一版不再提醒。
  右上角「v版本・更新內容」可看版本時間軸，也可以按「檢查更新」手動檢查。
  最新版本在 GitHub：https://github.com/gn01918004-hub/calculator
  畫面最下方與報表右上角都會顯示目前使用的版本。
